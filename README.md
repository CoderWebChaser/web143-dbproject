# Arrow Dance Mayhem Category Database Generator

An ADM database with categories and songs built using SQLite3 with a Python script.

## Built with:
- Python
- SQLite3

## Run locally:
1. `python build_db.py`
2. `sqlite3 fm4songs.db`
3. `PRAGMA quick_check`
